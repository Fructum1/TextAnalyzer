**Требования**

Python 3.8+

numpy

scipy

**Запуск и сборка**

Установить зависимости (numpy, scipy), например, с помощью pip и команды 'pip install -r requirements.txt'

Сборка не требуется, для запуска необходимо в командной строке перейти в директорию с исходным кодом (находясь в папке src) и выполнить 'python Program.py' c параметрами, описанными в следующем разделе.

**Использование**

Программа представляет из себя консольное приложение для анализа русского текста. Из внешних зависимостей, помимо описанных в требованиях, применяется стемминг от Yandex mystem. Для ввода в программу возможен ввод напрямую в аргументе при вызове, а также через текстовые файлы с расширением .txt.

**Для запуска использовать команду ниже. А также примеры конкретных команд.**

В аргументах --file2 | --input2 можно передать список, разделяя файлы/входную строку через пробел и запятую. 

Флаг --compare доступен только при переданном --mode lsa, который будет сравнивать аргумент -f/-i с -f1/-i1. 

Флаг --num-topics доступен только при переданном --mode lsa.

'python analyzer.py --mode <mode> [--input|-i <text>] [--input2|-i2 <text2>] [--file|-f <file_path>] [--file2|-f2 <file2_path>] [--compare] [--num-topics <num>]'

**Анализ тональности текста:**


'python program.py --mode sentiment --i "Кот по имени Мурзик обожает играть с клубком шерсти и прыгать по мебели. Мурзик — это пушистый комок счастья, который делает каждый день ярче."'

'python program.py --mode sentiment --f <filePath>'


**Анализ LSA:**

'python program.py --mode lsa --input "Кот по имени Мурзик обожает играть с клубком шерсти и прыгать по мебели. Мурзик — это пушистый комок счастья, который делает каждый день ярче."'

'python program.py --mode lsa --file <filePath>'


**Анализ LSA со сравнением:**

'python program.py --mode lsa --compare --input "Кот по имени Мурзик обожает играть с клубком шерсти и прыгать по мебели. Мурзик — это пушистый комок счастья, который делает каждый день ярче." --input2 "Котик по кличке Барсик очень любит кушать рыбные консервы и лакать молоко из блюдца. Барсик — это пушистый друг, который делает дом живым и радостным."'

'python program.py --mode lsa --compare --file <filePath> --file2 <filePath>'


**Комбинированный анализ:**

'python program.py --mode sentiment,lsa --input "Кот по имени Мурзик обожает играть с клубком шерсти и прыгать по мебели. Мурзик — это пушистый комок счастья, который делает каждый день ярче."'


После обработки программа выводит результат в виде оцененной тональности (с градациями "Позитивная тональность", "Негативная тональность" и "Нейтральная"), числовой оценке тональности, а также количестве слов, повлиявших на оценку. При выборе LSA выводится важность тем, характеристики получшегося словаря, а также топ-слов по темам.
