Сборка не требуется, для запуска необходимо в командной строке перейти в директорию с исходным кодом (находясь в папке src) и выполнить 'python Program.py' c параметрами, описанными в следующем разделе.

**Использование**

Программа представляет из себя консольное приложение для анализа русского текста. Из внешних зависимостей, помимо описанных в требованиях, применяется стемминг от Yandex mystem (https://yandex.ru/dev/mystem/). Для ввода в программу возможен ввод напрямую в аргументе при вызове, а также через текстовые файлы с расширением .txt.

**Для запуска использовать команду ниже. А также примеры конкретных команд.**

'python analyzer.py --mode <mode> [--input|-i <text>] [--input2|-i2 <text2>] [--file|-f <file_path>] [--file2|-f2 <file2_path>] [--compare] <compare_mode> [--num-topics <num>]'

В аргументах --file2 | --input2 можно передать список, разделяя файлы/входную строку через пробел и запятую. 

Аргумент --compare доступен только при переданном --mode lsa, который будет сравнивать аргумент -f/-i с -f1/-i1. При передаче аргмуента--compare нужно указать алгоритм для сравнения (доступно tdidf/w2v (для анализа с использованием Word2Vec)/rnn). При использовании w2v модель обучается на переданном корпусе, использование уже обученных модулей пока не предусмотрено. При использовании rnn запускается сравнение с применением уже обученной рекуррентной нейронной сети. 

Генерация текста происходит при выборе --mode lsa

Флаг --num-topics доступен только при переданном --mode lsa.

После обработки программа выводит результат в виде оцененной тональности (с градациями "Позитивная тональность", "Негативная тональность" и "Нейтральная"), числовой оценке тональности, а также количестве слов, повлиявших на оценку. При выборе LSA выводится важность тем, характеристики получшегося словаря, а также топ-слов по темам.

**Сравнительное описание анализа схожести с помощью W2V, TD-IDF, RNN**

*TD-IDF + LSA:*

Векторизация на основе частоты слов и тем

Хорошо показывает ключевые слова и тематические направления

Не учитывает семантическую близость синонимов

*Word2Vec:*

Векторизация на основе смыслового контекста слов

Учитывает семантическую близость и синоним

Требует предобученной модели или времени на обучение собственной

*RNN:*

Сравнение документов на основе обучаемых представлений

Учитывает порядок слов, контекст и смысловые зависимости

Требует обучающего набора и времени на обучение, но даёт более точную оценку сходства текста. Оценка напрямую зависит от качетства обучающего корпуса.

**LSTM и Seq2Seq:**

    *LSTM:*

        Архитектура рекуррентной сети с механизмами памяти для обработки последовательностей

        Эффективно улавливает долгосрочные зависимости в данных

        Обрабатывает последовательности входов и выдает последовательность скрытых состояний, но не предназначена для прямой трансформации последовательностей разной длины

    *Seq2Seq:*

        Архитектура для преобразования входной последовательности в выходную произвольной длины

        Состоит из кодировщика (обычно RNN/LSTM) и декодировщика, что делает её универсальной для задач перевода, суммаризации и генерации текста

        Позволяет работать с последовательностями разной длины на входе и выходе, что является ключевым отличием от простых RNN/LSTM
